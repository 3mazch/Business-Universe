# Source code

`src/` chứa mã nguồn tạo dữ liệu cho Flex Coffee & Tea:

- [`data_generation/`](data_generation/README.md): pipeline sinh dimension và mô phỏng Sale/Orders.
- [`utils/`](utils/README.md): constants, xử lý ngày, seed tái lập và logic cửa hàng được các engine dùng chung.

Các script ghi kết quả vào `data/`; xem README của từng module để biết đầu vào, đầu ra và cách chạy.
